  (int_pit_strategy_value.sql lines ~61-72). All 734 missing stints have zero valid laps in int_stint_geometry (734/734),
  so they never enter the model. 546 have stint_length_laps <= 2; by end cause: red 175, sc_pit 160, retirement 158,
  green_pit 149, race_end 61, vsc_pit 29, none 2.
  Proposed transform fix: either (a) make the final select start from int_stint_end_regime / fct_stint_features and LEFT JOIN
  the simulation outputs, leaving verdict columns NULL for stints with no valid lap, or (b) emit a stub row per stint with
  actual_pit_lap/end_lap_number filled from int_stint_end_regime. Option (a) fixes the page query with no workaround, and
  would let the Gantt query drop the cumulative-length derivation. Also add int_stint_end_regime to the export if the page
  should use the true end lap.
