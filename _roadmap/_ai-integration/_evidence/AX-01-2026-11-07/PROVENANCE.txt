Decisions (run notes)
  - Validator: HAND-WRITTEN schema interpreter, NO ajv, no dependency added. validate.ts evaluates
    card.schema.json itself (keywords: type enum const pattern minLength minimum maximum required
    properties additionalProperties items if then not anyOf allOf); a test fails if the schema uses
    any other keyword. Reason: no validator in package.json; the only ajv in node_modules is
    eslint's ajv 6 (no 2020-12). Semantic checks a schema cannot state: low <= high, id starts
    with kind + ':', interval.kind == expectedIntervalKind (relabel check), finite value.
  - Finding 3 applied: interval may be null for measured/computed AND for unavailable/held.
    The modelled/experimental interval rule applies only when status != held.
  - Finding 4 applied strictly: n.count integer >= 0 on every card and == 0 on held and
    unavailable cards (enforced by the schema).
  - interval.kind enum includes ci_normal_95 and ci_order_stat_median. When kind != none,
    low/high must be numbers.
  - Projection: v and iv numbers rounded to 6 significant digits; `why` (held/unavailable reason)
    clipped to 64 chars with an ellipsis (full reason stays on the card). Without the clip a
    realistic held reason gave 74 tokens (> 70 bound). m = metric with '_' -> ' '.
  - toCheckerCard passes through id, kind, metric, label, status, value, unit, scope, caveats,
    sample, grade, interval and flattens n/n_unit/source_page/source_table/model_version/policy_fields.
