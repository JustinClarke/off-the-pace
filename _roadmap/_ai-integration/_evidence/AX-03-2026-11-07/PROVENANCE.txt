Behaviour notes
  - Season bounds 2018..latestSeason(): manifest stats.seasons_list max when loaded, else LATEST_SEASON (2025).
  - A race key (2024_8) also sets season=2024 when the route reads season (the pages list races per
    season, so without it the link would select nothing); a contradicting season is refused.
  - Waterfall race encode round_int: race=2024_8 -> season=2024&race=8.
  - Routes whose page does not read season (e.g. /drivers/ratings-timeline, /tyre-strategy/recovery,
    /drivers/circuit-affinity, /drivers/wet-race, /constructors/circuits, /ml/metrics, pillar roots)
    get an EMPTY entry, so navigate refuses season there.
  - Denied keys on every route: sql, url, query, href, redirect. Errors return {ok:false, error, key, allowed}.
  - cardLink returns null for: no page, unknown route, any invalid param, or params that name a
    different race/driver than card.scope (link must select what the card describes).
