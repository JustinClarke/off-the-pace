Design notes
  - Publish gate: spec.held -> held; else class not in classesLive -> held "CLASS_NOT_LIVE ..."; else value.
    With classesLive = [] EVERY card is held today. AX-07 adds 'T' (and 'T-F' per HD13) to classesLive.
  - registryHash covers declarative spec fields + rev + caveat codes + classesLive; NOT function bodies
    (Vite SSR / vitest / browser rewrite imports inside them differently, so the hash would depend on the
    loader). Logic changes must bump `rev`. Current hash: 52ac83f4ac922934bdbf3f6b4dcf074ef9a842465d5965b21842398dcff469d6.
  - Seam swap gotcha found and fixed: a stand-in that imports the real module must get it under a distinct
    id (`?ax04-real`), otherwise Vite's url->module cache hands the stand-in back to itself.
  - Adapter maps CDN / origin / server-relative URLs to <dataDir>/..., drops ?v=, refuses paths outside
    /data/ or escaping dataDir; directories are registered file by file (browser globs over HTTP).
  - buildCards: refusal -> one ungrounded entry per id the refusal covers; missing n -> ungrounded;
    validateCard failure -> ungrounded "invalid card: ..."; duplicate id -> ungrounded; compute error -> ungrounded.
