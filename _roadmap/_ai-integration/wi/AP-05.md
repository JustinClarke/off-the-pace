# AP-05 - constructor-team-averages averages dirty air over the filled zeros

**Group:** 2 app fixes · **Depends on:** TX-03 · **Model/cost:** sonnet-5, 0.25d · **Blocker:** none.

**Sources:** `app/src/features/constructor-team-averages/queries.ts`, `transform.ts`, the TX-03 evidence (`_evidence/TX-03-2026-11-07/PROVENANCE.txt`), AP-01 (same pattern).

## Problem
`queries.ts:34` averages dirty air with no guard. Laps where dirty air could not be measured carry a filled 0.0 (6,460 laps), so they count as measured zeros and pull the average down. TX-03 made "no dirty-air row <=> `pace_delta_s IS NULL`" a tested invariant.

## Method
1. Average dirty air only over laps where `pace_delta_s IS NOT NULL`; return the count `n_dirty_air_laps` next to it, as AP-01 did for the waterfall.
2. When the count is 0 for a team-season, return NULL and render "unavailable", never 0.
3. Re-read AP-01's `waterfallBars.ts`/tests for the house pattern; do not change AP-01's files beyond reuse.

## Acceptance
A team-season whose dirty-air laps are all filled shows "unavailable" (test). A team-season with a mix equals the mean over the measured laps only (test, fixture). Other columns in the query are unchanged.
