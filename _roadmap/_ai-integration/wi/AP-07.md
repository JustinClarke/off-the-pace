# AP-07 - Season Structural Pace interval, Party Mode labels, Races column

**Group:** 2 app fixes · **Depends on:** AP-03 · **Model/cost:** sonnet-5, 1d · **Blocker:** none (the owner asked Opus to decide; the ruling is below).

**Sources:** `_evidence/AP-03-2026-11-08/opus-ruling.md` (READ FIRST: decisions, evidence, exact spec), `PROVENANCE.txt` there, and the code in `app/src/features/constructor-structural-pace/` and `app/src/features/party-mode/`.

## Decided (Opus, 2026-11-08)
1. Season interval: point stays the plain mean. SE = sqrt(max(VAR_SAMP(p), mean(se^2)) / k). CI = mean +/- t_97.5(k-1) x SE (lookup table, DuckDB has no t quantile). k < 3: SE and CI are NULL, shown as a dash. Worked case: Mercedes 2020 mean -1.2733, SE 0.1004, CI [-1.4873, -1.0594].
2. Party Mode: three labels. party = delta < -0.15 and CI wholly below 0; race = delta > 0.15 and CI wholly above 0; else "no clear gap"; NULL delta -> no label. "Balanced" is retired. Season delta = AVG(q - r) over races that have both values (the old AVG(q) - AVG(r) skips different races).
3. Races column = k (races with an estimate), with a tooltip saying so; Obs counts only those k races.

## Method
Follow the implementation spec in the Opus report: season branch of both `queries.ts`, both `transform.ts` (t975 table, nullable SE/CI, CSV `interval_method`, `delta_ci_covers_zero`, `races_n`), `page.tsx`, `methodology.tsx` (rewrite the lower-bound paragraph, retire the Balanced badge, add No clear gap). Race-grain estimates on both pages must not change.

## Acceptance
Mercedes 2020 race mode reproduces the worked case to 12 dp (test). k=1 and k=2 give no SE/CI (test). A fixture with a CI covering 0 never gets party or race. Race-level label counts: party 364, race 382, no clear gap 856, 42 with no delta (verify on the scratch warehouse and report any difference). Full vitest keeps only the 2 pre-existing failures.
