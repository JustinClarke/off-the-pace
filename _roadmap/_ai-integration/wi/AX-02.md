## Decided (design 2.5, AD2)

- `list_values` is one of the seven tools. Input `{domain, query?, season?, limit<=20}`. Output `[{code, display, aliases_matched, seasons}]`, at most about 400 tokens, at most 20 rows.
- Domains: `driver, constructor` (with `constructor_lineage_id`), `race` (season, round, race_id, circuit, GP name), `circuit, season, compound` (per season), `caution_status, stint_end_cause, card_kind, page, columns` (with `view`).
- Fuzzy matching runs over an alias list ("Checo" resolves to `PER`; "Alfa Romeo", "Sauber" and "Kick Sauber" resolve to lineage `sauber`).
- `list_values(domain:"columns")` plus validation errors replace a separate describe tool, so the tool count stays seven.

## Findings

1. **No display-name table exists.** `dim_drivers` has only `driver_id` (FastF1 three-letter code), `driver_number`, `debut_year`, `career_races_in_dataset` (schema.yml:163-183). "Checo" cannot resolve today.
2. **`useDrivers.ts` is broken and unused.** Line 17 runs `SELECT * FROM dim_drivers ORDER BY last_name`; `dim_drivers` has no `last_name`. A grep of `app/src` on 2026-11-07 finds no importer. Delete it, or rewrite it over `assistant_entities`. This clears watch AXW10.
3. **Race names exist in bronze, not in any published table.** `race_to_track` maps `race_id` to a slug and `dim_circuits.circuit_name` gives the circuit, but not the Grand Prix name. `data/bronze/schedule` `EventName` plus `RoundNumber` does; `race_id` is `{season}_{round}` (`useRaceOptions.ts` splits it that way).
4. The entity table cannot be built from published files alone (names live in bronze). It is reference data and is itself published, so it is the one allowed exception to "built from `app/public/data`". Record that in the export's comment.

## Method

1. Add `export_assistant_entities(conn, out_root, size_report)` to `scripts/export_app_data.py`, called from `_run_export_to` (around line 665) and writing `data/dimensions/assistant_entities.parquet` with a manifest entry. Build it with DuckDB `read_parquet` over the bronze globs above plus `dim_drivers`, `dim_constructors`, `dim_circuits`, `race_to_track`, `dim_compounds_season`. One row per `(domain, code)`; columns `domain, code, display, aliases (json list), seasons (json list), parent_code, extra (json)`.
2. Driver names: `driver_standings` (`driver_code` -> `given_name family_name`); fill gaps from `results` bronze (`Abbreviation` -> `FullName`). The export fails, naming the codes, if any `dim_drivers.driver_id` has no name from either source. Display is `Given Family (CODE)` unless the owner rules otherwise under HD7.
3. Aliases live in a checked-in file `app/src/assistant/entities/aliases.json` (nicknames, constructor renames, circuit nicknames). The export merges it into `aliases`. Seed at least the 30 fixtures below.
4. `app/src/assistant/listValues.ts`: loads the table once through `registerParquet` (same pattern as `useRaceOptions.ts:30-45`), normalises the query (lowercase, strip accents and punctuation), matches exact code, then alias, then prefix, then token overlap, and returns at most `limit` rows ranked in that order. Static domains (`season`, `caution_status`, `stint_end_cause`) come from the table; `page` from `routeToPageId`; `columns` and `card_kind` are provider hooks that return an empty list with a `note` until AX-05 (catalogue) and AX-04 (registry) register theirs.
5. Session cache: remember resolved `(domain, query)` pairs so repeats cost no call (design 2.6).
6. Delete or fix `useDrivers.ts` (finding 2).

## Acceptance

- Every `driver_id`, `constructor_id` and `race_id` that appears in the exported tables of the manifest resolves to a row (test reads the published parquet, or a fixture set when the local `app/public/data` holds only 5 files; see Notes).
- 30 alias fixtures resolve to the right code, including "Checo"->`PER`, "Alfa Romeo"/"Sauber"/"Kick Sauber"->lineage `sauber`, "Interlagos 2021"->`2021_19`.
- Each call returns at most 20 rows and at most 400 tokens (`estimateTokens` from `nav/pageSummaries.mjs`).
- `useDrivers.ts` no longer queries a missing column.
