## Findings that change the method

1. **The checker only sees cards.** `CheckInput` is `{question, answer, cards}` (checker.ts:31-35). A query-builder result is not a card, so `computed_not_card` has nothing to trigger on. Add `queryResultToCheckerCard(result)` in `app/src/assistant/honesty/queryCard.ts`, producing `{id: result_id, metric: "<view>.<measure>", label: "computed_not_card", n: min(row n), n_unit: "rows", source_page: <view>}`; AX-10 passes these into `cards`. Triggers read `label` and `status`, which AX-01's `toCheckerCard` now passes through.
2. **"One skill definition per answer" needs a new trigger.** The existing triggers cannot say "two or more cards carry different values of a field". Add one variant to `Trigger` and `evalTrigger`: `{cards_distinct_values: {field, min}}`, fired when at least `min` distinct non-null values of `field` appear across the supplied cards. Add tests; leave every existing branch unchanged. The measure name travels in `policy_fields.skill_measure` (set by the card kinds in AX-07/AX-15a; AX-21's glossary names the six values). The audit counts six shipped "skill" measures (waterfall residual, consistency residual, wet-race proxy, LORO race skill, era-normalised rating, corner/synthetic/qualifying proxies) whose ranks can disagree.
3. **`CALIBRATION_FLAGGED_CIRCUIT` has no producer.** It fires on `calibration_flag in [REVIEW_REQUIRED, INSUFFICIENT_DATA]`, but no exported table carries the column: `grep` finds `calibration_flag` only in `policy.json`, the generated page summaries and the seed `transform/seeds/circuit_reference.csv`; it is absent from `dim_circuits` (reference/schema.yml) and from `export_app_data.py`. This item cannot fix it (it is a transform and export change); add a `not_fired` example that records the gap, and flag it to the owner as a separate item.
4. TX-04 (dirty-air SE and method honesty) must land first so the dirty-air wording describes the SE as it will be (today a fixed 15% of the estimate, `int_dirty_air_tax_component.sql:354`, per the log; not re-read here).

## Method

Add seven rules (code, kind, trigger, required wording in plain terms; numbering kept from the earlier draft, rule 4 removed). Declare the two new kinds, `computed_not_card` and `held_card`, in `policy.kinds` (a test requires every rule's kind to be declared). Write each pattern and example by running it through `checkRule`; keep patterns narrow so passing answers in all rules still pass the whole policy (`checker.test.ts` runs every passing example against every rule).

1. `COMPUTED_NOT_CARD_WORDING` (new kind `computed_not_card`): trigger `label eq computed_not_card`. Required: say it is a plain count, average, median or total from the data. Forbidden: calling it a rating, modelled, predicted or "skill". Source: AD3 text above.
2. `HELD_CARD_WORDING` (new kind `held_card`): trigger `status eq held`. Required: say the figure is not available yet and held, and why (waiting on wake calibration, the ML redo or the pit-call re-measure). Forbidden: any estimate or "probably" for the held figure.
3. `UNAVAILABLE_IS_NOT_ZERO` (`known_gap`): trigger `label eq unavailable`. Required: no value / not measured / unavailable. Forbidden: reading it as 0 or "no difference". Complements `MISSING_RATING_IS_NOT_ZERO`, which stays.
4. *(Removed 2026-11-07: merged into TX-04's `DIRTY_AIR_MODELLED_NOT_MEASURED`, same trigger. Do not add `DIRTY_AIR_POOLED_ESTIMATE`.)*
5. `LAP_MAP_GREY_CELL`: trigger `source_page matches dirty-air-lap-map`. Required: a grey cell can mean clean air or missing telemetry. Source: dirty-air-lap-map.mdx:21.
6. `SURVIVAL_LOWER_BOUND`: trigger `source_page matches tyre-cliff-survival` and a survival metric. Required: "lower bound on tyre life" where the curve is mostly censored. Forbidden: "the tyre will last". Source: tyre-cliff-survival.mdx:34.
7. `GHOST_IS_COUNTERFACTUAL`: trigger `source_page matches ghost-race-standings|counterfactual-championship|hidden-performance`. Required: a statistical, expected-value reconstruction, not a simulation. Forbidden: "would have won", "proves". Sources: ghost-race-standings.mdx:21, counterfactual-championship.mdx:31. The "not independent evidence" warning (ghost standings, affinity and era ratings share a race-grain rating) is AX-21's `NOT_INDEPENDENT_EVIDENCE`, not a clause here. Keep the `cards_distinct_values` trigger extensible: AX-21 adds an optional `where` filter.
8. `ONE_SKILL_MEASURE` (`known_gap`): trigger `cards_distinct_values {field: skill_measure, min: 2}`. Required: name each measure and say they are different measures. Forbidden: ranking across them as one scale. Single-card form: any skill card requires the answer to name the measure.
Also: fix the contradictions list if any new rule exposes a doc conflict; record it, do not resolve it silently.
