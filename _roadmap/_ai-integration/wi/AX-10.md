## Token budget (design 2.6, replaces AD2's)

Instructions 1,200 · tool schemas 1,400 · query catalogue 600 · page context 600 · history 2,000 (last two turns, cards cited by id) · tool results 4,800 (4 x 1,200) · output 2,500. Peak 13,100. Bar for the eval is 18,000 (AX-13).

## Method

1. **Dispatcher** `app/src/assistant/core/dispatcher.ts`: `dispatch(call): ToolResult`. Exact tool names above. Arguments are validated against the generated schemas (`catalogue.json`); unknown tool, bad args or a refused call returns `{status:"error", reason, allowed}` as a tool result (never throws to the model). Wire: `get_fact_cards` -> AX-08 card store (up to 3 scopes x 5 kinds per call, at most 10 cards, model projection about 55 tokens each), and its **`bundle` argument** -> AX-21's `resolveBundle(type, scope)`, so one call returns a recipe's cards, held stubs included; `query_data` -> AX-06 builder only (never `runLabQuery`); `list_values` -> AX-02; `navigate` / `explain_page` -> `app/src/nav/assistantTools.ts`. `make_chart` and `compare_lap_times` are AX-11: register them as stubs returning `{status:"error", reason:"not_available_yet"}` until AX-11 lands, behind the same schema.
2. **Page-card pre-load.** On a new question, read the current route and params, call the registry's `onScreen(params)` (AX-07, at most 6 card ids) and put those card projections in the page-context slot. A question about the on-screen number then needs 0 tool calls.
3. **Loop** `app/src/assistant/core/loop.ts`: at most 4 tool calls per question (5 model rounds, which AX-12's ticket also enforces). An empty or refused call goes back to the model, which may retry once or must say it has no data. "What if" tyre questions get the Degradation Simulator link, no computed answer (AI-05 stays closed). `list_values` results are cached for the session; a repeated code is not looked up twice.
4. **Budget meter** `core/budget.ts`: count tokens per slot (use `usage.prompt_tokens` from the model reply when present, else chars/4 and mark it estimated). Truncate a tool result to its 1,200-token slot and set `rows_dropped`; drop the oldest history turn before the history slot overflows. Emit one log line per question: slot -> tokens, total, rounds, neurons (`neuronsFor` formula, `worker/src/handler.ts:79`, rates `worker/src/config.ts:16-17`).
5. **Grounding module** `app/src/assistant/grounding.ts`: `findUngroundedNumbers(answer, sources)` where sources are the cards and `result_id`s returned this session. AX-14 reuses it at render time; do not fork it.
6. **Repair turn.** After the model drafts, run `checkAnswer({question, answer, cards})` (`checker.ts:206`) plus `findUngroundedNumbers`. On a failure, send one repair message listing failed rule codes, `missing_wording` and the ungrounded numbers; if the second draft still fails, return the draft with the failures attached as notes (AX-14 shows them) and never silently pass it.
7. **Headless CLI** `app/scripts/assistant-cli.ts`: `--endpoint <url>` (local Ollama or the AX-12 preview Worker), `--question "<text>"` or `--file questions.json`, `--page <route>` to simulate on-screen cards. Runs against published files in `app/public/data` through the AX-04 Node adapter. Do not add a runner dependency without asking; Node 24 can run TypeScript with type stripping, otherwise run it through vitest. Output: answer, tools called, cards cited, checker report, budget line.
8. **Close AI-10's open check:** run `explain_page` for 5 different pages in the CLI and save the five outputs to `_roadmap/_ai-integration/_evidence/ax-10/explain-5-pages.txt`.

## Acceptance

- Loop limit: a stub that always asks for another tool call is stopped after the 4th call and the model is told to answer from what it has.
- Empty result: the answer says there is no data and contains no number.
- Refused call (bad view, unknown tool, held card): returned as a structured tool error; the model's next turn does not crash the loop.
- Number without a source: an answer quoting a number not in any card or `result_id` fails the grounding check and triggers exactly one repair turn.
- Repair turn: a fixture that omits required wording passes after the repair and is flagged after a second failure.
- A `bundle: "teammate_race"` call for a (driver, race) returns the recipe's cards in one round (test with the store stubbed).
- 10 sample questions run headless, saved to `_evidence/ax-10/sample-run.json`: 3 card-only, 2 `query_data`, 1 `list_values` alias ("Checo"), 1 on-screen (0 tool calls), 1 held class refused with its reason, 1 what-if (link only), 1 `navigate`.
- Budget log shows every slot, and no run exceeds 13,100 tokens at the proposed slots.
