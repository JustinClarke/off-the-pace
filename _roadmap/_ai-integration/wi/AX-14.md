# AX-14 — Chat drawer with render-time grounding and label rendering, behind a flag (off)

**Group:** 4 assistant · **Depends on:** `AX-10`, `AX-12` · **Model / cost:** `sonnet-5`, 3d
**Blocker:** none. `HD1` ruled A on 2026-11-07 (foundations start now; transform-class cards only; PK1 stands for ML and the held classes). The Turnstile widget also needs AX-12's CSP change (`HD11` ruled yes) before it loads outside local development.

**Replaces:** v1 `AI-08` (`wi/AI-08-chat-ui.md`). Phone width, keyboard, screen reader, reduced motion, proxy-down message and "no number without a card" carry forward. New: render-time grounding, label rendering, and a correction on streaming.

**Sources (verified):** `app/src/ui/layout/AppShell.tsx`, `app/src/ui/feedback/` (`DataBoundary.tsx`, `EmptyState.tsx`, `ErrorBoundary.tsx`), `app/src/ui/TechTooltip.tsx`, `app/src/nav/assistantTools.ts`, `app/src/vite-env.d.ts`, `app/perf-budget.json`, `app/e2e/`, AX-10's loop and `grounding.ts`, AX-03's `navigate` v2, AX-12's Worker contract (ticket, 409, `paused`).

---

## Decided

- **Behind a flag, off by default.** No feature-flag mechanism exists in `app/src` (only `VITE_DATA_BASE`). Use a build-time Vite variable `VITE_ASSISTANT_ENABLED === 'true'`, declared in `vite-env.d.ts`. Switching it on is a rebuild and deploy, which is the owner's call (AX-20).
- **No streaming.** AI-08 asked for streaming, but the Worker returns one JSON reply (`worker/src/handler.ts:170`) and the checker must run before anything is shown (design 2.8). Show step progress ("Looking up cards...") then the checked answer. Do not add streaming.
- Every number links to the page that explains it, using the card's `page.route` and `params` through `navigate` v2 (AX-03). The model never writes a URL (rule 6).
- Rendering follows the card label: `measured` plain; `modelled` hatched/greyed with the word "modelled" and, for traffic-cost values, the exact WC disclaimer once those exist (AX-09 wording); `unavailable` shown as "—" with its reason, never 0; `computed_not_card` tagged "plain count/average".

## Method

1. Files under `app/src/assistant/drawer/`: `ChatDrawer.tsx`, `useChat.ts` (calls AX-10's loop through the Worker, handles ticket, 409, 429, 503), `AnswerView.tsx`, `NumberChip.tsx`, `TurnstileGate.tsx`. Mount from `AppShell.tsx` only when the flag is on; lazy-load the whole drawer (`React.lazy`) so the bundle budget in `perf-budget.json` is unaffected when off.
2. **Render-time grounding.** Tokenise numbers in the answer; each must match a card in this session's store (value at `display` precision) or a `result_id` result via `findUngroundedNumbers`. A match becomes a `NumberChip` with a link to the page and a popover (hover, focus and tap) with value, interval (low-high, kind, level), n and unit, label, `label_version` and `model_version`. A non-match is struck through with the AI-02 note "this number is not backed by a card or a query result".
3. AI-02 rule hits and `checker` failures render as a visible note on the answer, not buried text. Held-card answers show the held reason.
4. Failure states: network error or Worker down -> plain message, rest of the app unaffected; 503 `paused` -> "answers are paused for today"; 429 -> "daily question limit reached"; 409 `app_updated` -> "the app was updated, reload to keep asking" with a reload button; Turnstile failure -> retry prompt.
5. Reuse `DataBoundary`, `EmptyState`, `ErrorBoundary`; use `TechTooltip` for first-use terms. Drawer reachable from every page; keyboard open/close (Escape closes, focus returns to the opener, focus trapped while open); `aria-live="polite"` for the answer; `prefers-reduced-motion` disables the slide animation; 16px gutters, no horizontal scroll at 320px.
6. Charts from AX-11 render inline through `ChartCard`; chart rows never go to the model.

## Acceptance

- Flag off: no drawer in the DOM, no extra chunk requested, bundle budget (`pnpm bundlesize` after build) unchanged.
- Flag on: works at 320px and 390px width, by keyboard only, with a screen-reader name/role check (Playwright accessibility snapshot or `@testing-library` role queries), and with reduced motion.
- An unmatched number is struck and noted; a matched number links to the right page and opens its popover.
- Proxy down, paused, limit, 409 each show their message and leave navigation working.
- `modelled`, `unavailable` and `computed_not_card` fixtures render their distinct labels; unavailable never shows 0.
- Existing e2e tests (`app/e2e/`) and the perf budget still pass.
