## Method (build against fixtures and a scratch copy until the lift)

1. Registry kinds (class `ML`): `ml.pred_band` (p10/p50/p90 per circuit x compound x lap-in-stint or stint; `interval.kind = pred_band_p10_p90`, level 0.8, `value` = p50), `ml.cliff_prob`, `ml.envelope` (in-envelope boolean and distance from `mart_degradation_history_envelope`), `ml.metric` (per model: the metric, with its CI where published), `ml.blind_test`.
2. `versions.model_version` is read from `ml/models/manifest.json` / `app/public/models/manifest.json` using the HD8 string; refuse to build if the two manifests disagree.
3. Caveats from the registry, not from the model text: 2018 rows get `sample:"in_sample"` (CD2) so `IN_SAMPLE_FIT` fires; CV metrics get the `CV_FOLD_NOT_CLEAN_HOLDOUT` caveat; prediction cards outside the envelope set `caveats:["OUTSIDE_ENVELOPE"]` and still carry the band; 2026 requests resolve to `NO_2026_DATA`.
4. Every prediction card needs a band (rule `PREDICTION_CARRIES_BAND`); a point value without p10 and p90 is refused with a reason.
5. Registry guard test (watch AXW6): no kind may read `flag_chance_lookup.json`.
6. Page links via `onScreen`/`pageParams` to `/ml/...` routes in `routes.ts`.
