# AX-18 — Pit-call verdict cards with the measured reproduction rate

**Group:** 5 held classes · **Depends on:** `AX-17` · **Model / cost:** `opus-5`, 1d
**Blocker:** `XM` (external, not an owner call): the ML redo lands, `CD10` (which model version is promoted) is ruled, and the D9/D14 re-measures (watch W7, AXW8) are recorded on the redo model. In plain words, the pit-call "optimal lap" comes from the cliff model, and how often it reproduces the team's real call was only measured on an old model, so no verdict may be given until it is measured again.

**Sources (verified):** `transform/models/intermediate/int_pit_strategy_value.sql`, `app/src/features/pit-strategy/` (`queries.ts`, `transform.ts`, `page.tsx`), `app/src/assistant/honesty/policy.json` rule `PIT_CALL_REPRODUCTION_RATE` (its `source_table = int_pit_strategy_value` and metric trigger list: `optimal_pit_lap_in_stint`, `strategy_verdict`, `overrun_laps`, `opportunity_cost_s`, `optimal_pit_lap_confidence`), `docs/app/pit-strategy.mdx`, `_evidence/ax-audit-2026-11-07/audit-app.md` section 3 chain 4, design 2.4 (pit-strategy row: "T but held").

## What is held, why, and what lifts it

**Held: all pit-call verdict cards** (`pit.verdict`, `pit.optimal_lap`, `pit.opportunity_cost`, `pit.overrun`, `pit.confidence`), published as `status:"held"`, `value:null`, `held_reason` = "the pit-call verdict has not been re-measured on the current model". Why: the reproduction rate behind them (policy `PIT_CALL_REPRODUCTION_RATE`) was measured on v11 against the unrefit seed (policy source `CO-07-stale-rulings.md`) and is owed a re-measure on the redo model.

**Until the lift, the assistant may describe the stint only.** Stint-describe cards are not held: stint number, compound, start and end lap, actual stop lap and pit-lane loss (observed, from `qv_pit_stops` / AX-07), with the Race Control safety-car timing as context. If the user asks "was the pit call right", the answer describes the stint and says that no verdict is available yet; if it mentions the reproduction rate it uses the policy's wording.

**Wording to carry:** the rule requires the measured realised-call reproduction rate in any answer touching those metrics, and forbids "should have pitted" / "definitely too early/late". The 33.9% figure is the interim wording. **Check before using it:** the rule's own description says "33.9% within +/-2 laps", but its source quote (`_roadmap/_improvements/status/build-log.json` line 977, as recorded in policy.json) says "right about the realised call 33.9% of the time or 53.0% of the time at +/-2 laps". Report which reading is right to the orchestrator; do not publish wording until it is settled.

**Lift:** `XM` resolved; the re-measured rate recorded; the rate is stored as a field in the verdict card (not only in the prose); the owner's yes. Then verdict cards stop being held. Not before.

## Method

1. Build `cards.ts` in `app/src/features/pit-strategy/` for the five verdict kinds (class `T` by lineage but `status:"held"` via a `HELD_KINDS` list in the registry keyed on `XM`), using the page's own `queries.ts` + `transform()` run headless.
2. Add card field `reproduction_rate: {value, within_laps, source, measured_on_model_version}`; the builder refuses to un-hold a verdict card whose `reproduction_rate` is null or whose `measured_on_model_version` differs from `versions.model_version`.
3. Stint-describe kinds: confirm AX-07 produced them (they should not be held). If not, add them here as `measured` cards with `n` = laps in the stint.
4. Policy: confirm `PIT_CALL_REPRODUCTION_RATE` fires on each verdict metric and passes only with the reproduction wording; update the rule's description/wording only to the settled reading, with a source line (`sources.node.test.ts` requires one).
5. Page links to `/pit-strategy` with race and driver via AX-03.

## Acceptance

- While `XM` is open: 100% of verdict cards are `held`; stint-describe cards are live; an answer to "was the pit call right" in the stubbed loop describes the stint and gives no verdict.
- `PIT_CALL_REPRODUCTION_RATE` passes on fixtures that carry the rate wording, fails on one that omits it and on one that says "should have pitted".
- The un-hold guard test: a verdict card with null rate, or a rate measured on another model version, cannot be built live.
- After the lift: each verdict card carries its rate and the policy rule passes on it; parity with the pit-strategy page for 10 stints across at least 3 seasons.
