## Decided

- The freeze is a file, not a promise: `_roadmap/_ai-integration/_evidence/ax-19-freeze/freeze.json`, written by a script, verifiable by the same script.
- It contains: `manifest.version`, `generatedAt`, per-partition `assistant.cards[]` `{season, path, rows, sha256}`, `catalogue_version`, `registry` hash, `label_version`, `model_version` (or null), `classes_live`, `classes_held`, and per card-source table the row count and file sha256.
- The snapshot is only valid if `generatedAt` is after the v16 seal (CO-33, 2026-10-26); today's published manifest (2026-10-16) is not (watch AXW3, HD12).

## Method

1. **Gate.** Read HD5 in the log. If unresolved, stop. If A: confirm `classes_live` is `["T"]` (plus any class whose gate item landed). If B: confirm AX-17 is LANDED and `XM`, `CD10` resolved. Confirm `generatedAt` is after 2026-10-26, and AX-13's bar passed in its baseline (a failing baseline means do not freeze: report).
2. **Re-export on the sealed build** is the owner's yes (HD12). `make app-data` rewrites tracked files under `app/public/data/`; never run it unasked. If a re-export is needed and approved, follow the scratch-folder rule: parallel dbt work uses its own folder with the copy named `dev.duckdb`. Do not touch `data/*.duckdb` otherwise.
3. **Write the script** `scripts/assistant_freeze.py`: `--write` produces `freeze.json` from the manifest and the files on disk (sha256 of each cards partition, `catalogue.json`, `index.json`; row counts from parquet metadata); `--verify` recomputes and diffs, exit 1 on any difference, naming the field.
4. **Reproducibility.** Run `export_app_data.py --check` (regenerates the manifest and cards checksums without writing, per AX-08) and `assistant_freeze.py --verify`; both must pass on an unchanged warehouse.
5. Record in `freeze.json` a human line: which classes launch, which are refused and the held reason for each (this is what AX-20 and the eval check against).
6. Add `assistant_freeze.py --verify` as a `make` target `assistant-freeze-verify` and as a step the owner can add to CI; do not edit workflows unasked.

## Acceptance

- `freeze.json` exists with every field above, none empty except `model_version` under HD5-A.
- `--verify` passes immediately after `--write`.
- A re-export with an unchanged warehouse reproduces every checksum (`--check` + `--verify` pass).
- Changing one byte of one card partition makes `--verify` exit 1 and name the partition.
- `board.py --check` passes (run `python3 _roadmap/_ai-integration/status/board.py --check`).
