## Method

1. **New model** `transform/models/marts/mart_race_coverage.sql`, one row per `race_to_track` race (173): `race_id, race_year, circuit_id, n_lap_rows` (fct), `n_ml_eligible_laps`, `base_measured_share`, `residual_measured_share`, `rain_lap_share`, `tyre_qa_status` (`quarantined_race` / `partial` when any `quarantined_driver` lap / `ok`), `has_telemetry`, `n_rated_drivers` (race mart), `has_rating`, `coverage_reason`. `has_telemetry`: derive from data (share of laps with a measured air state in `int_lap_air_state`, threshold `var('isolation_thin_min_air_measured_share')` = 0.5, whose comment already says 2018_1/2 are 6% measured), and add a test that it is FALSE on exactly 2018_1 and 2018_2, the `KNOWN_TELEMETRY_GAPS` list.
   `coverage_reason` codes, first match wins: `NO_RACING_LAPS` (2021_12), `ALL_WET_NO_DRY_PAIRS` (2021_16; only when the race also has no rating, since other wet races such as 2020_14 are still rated), `NO_TELEMETRY` (2018_1/2), `TYRE_QA_QUARANTINED` (2018_3, 2025_6), `TYRE_LIFE_PARTIAL` (2022_7, 2022_11), `OK`. Derive them from the columns, never from a hand list of race ids. Reading `stg_lap_tyre_qa` (a view) is fine inside a dbt build from `transform/`.
2. **Race mart:** add `ci_unavailable_reason` (`PAIRED_N_BELOW_MIN` after TX-01, else NULL) and `residual_unavailable_reason` for the NULL `n_clean_laps` / component means (`NO_TELEMETRY`, `TYRE_QA_QUARANTINED`, `NO_ML_ELIGIBLE_LAPS`, NULL when present). Values in existing columns do not change.
3. **Season mart:** add `n_races_unrated` (races the driver has in `fct_lap_residuals` that season with no race-mart row), so 2021_16 is visible from the season grain. No existing value moves.
4. `schema.yml`: describe the new model and columns; fix the stale `stg_lap_tyre_qa` text. Do not edit README.md (TX-10 owns the counts); hand back the 173 / 172 / 171 split for it.

**Must not move:** label v16 and `label_stability_baseline.csv`; every existing column value in both rating marts; other marts; every `fct_*` hash in your own `$S/before.json`.
