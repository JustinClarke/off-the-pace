## The problem (re-verified 2026-11-07 on the audit's scratch build)

- `int_dirty_air_tax_component.sql:354` sets `dirty_air_tax_se_s = ABS(θ × share_lag1 × 0.15)`. The schema calls it "Standard error of the tax estimate via propagation". Nothing is propagated.
- **Count correction.** The log and audit say "all 161,040 rows". `int_dirty_air_tax_component` has **149,452** rows: 46,483 non-zero tax, all with SE/tax = 0.15 exactly; 102,938 with tax 0 and SE 0; 31 NULL. The 161,040 figure is `fct_lap_residuals`, where 161,009 rows satisfy SE = 0.15 × |tax|; that includes the 11,588 zero-filled laps (TX-03), where 0 = 0.15 × 0 holds trivially. The claim holds, but on these counts.
- The share is one bit per lap, so the tax takes two values (0 or 0.331 s) and the SE takes two values (0 or 0.0497 s). A clean-air lap carries zero uncertainty.
- `tax_calibration_confidence` is one value on every row, **0.996333**: n/(n + 500) over the calibration panel, a sample-size statistic. The schema already says so (1585-1591) and that per-season θ straddles zero in 2021 and 2024. `fct_lap_residuals` does not carry it, but `int_lap_residual_decomposed` does, as `dirty_air_tax_confidence`.
- θ = 0.331 s/lap is a declared var fitted outside dbt (F2: 0.3313 [0.293, 0.370], n = 138,679). WC-03/04 closed with no verdict (DD-WC15: "the flat penalty stays"). WC-10 has fitted nothing. Every dirty-air number is "modelled, flat 0.331 s/lap × share, method not validated".
- A θ-interval SE would be (0.370 − 0.293) / (2 × 1.96) = 0.0196 s per dirty lap, **smaller** than today's 0.0497. Replacing the convention would narrow the band, so it is not a free honesty win.
- `policy.json` has no rule for dirty-air values (rules: IN_SAMPLE_FIT … CHANCE_LINE_QUOTABLE; none on dirty air).
- Who reads the SE: `int_lap_residual_decomposed` → `fct_lap_residuals` (exported) and `int_qualifying_decomposed`. No label reads it. No file under `app/src` reads `dirty_air_tax_se_s`.

## Method (default: no value moves)

1. **Re-document, do not recompute.** Rewrite `intermediate/schema.yml:1578`, the only place `dirty_air_tax_se_s` is described, to: "Convention, not an estimate: 0.15 × the tax. Zero on clean-air laps. Not propagated from θ's interval. Do not quote as a standard error." Add the same description to the `fct_lap_residuals` entry in `marts/schema.yml`, where the column is undocumented today. This is the only place it is written (TX-10 no longer documents it). Lane M edits other entries of that file at the same time: edit only this entry and re-read the file just before saving. Add a matching comment above `int_dirty_air_tax_component.sql:354`. For `tax_calibration_confidence`, say it is constant per build and is not a confidence in the value.
2. **Method tag (trimmed 2026-11-07).** Add a var `dirty_air_method: 'flat_theta_0.331_lag1_share_unvalidated'` beside `theta_air_label_value` in `dbt_project.yml`, with a comment that it must change whenever θ or the method does. **No mart column:** TX-05's `mart_build_provenance` carries the var once, and each card carries it in `versions`. If TX-05 lands first and has already added the var, reuse it.
3. **Honesty rule** in `policy.json`: code `DIRTY_AIR_MODELLED_NOT_MEASURED`, kind `known_gap` (one of the ten existing `kinds`; adding a kind means editing `kinds` too), status `active`. Triggers: card caveat `DIRTY_AIR_MODELLED_NOT_MEASURED`, or a metric naming `dirty_air_tax`. Required wording: "modelled", with the flat 0.331 s/lap × share method named, and that it is **one pooled coefficient, not a per-car, per-circuit or measured value, which wake calibration may replace** (merged from AX-09's old `DIRTY_AIR_POOLED_ESTIMATE`; same trigger; also cite `docs/app/dirty-air-cost.mdx:35`). Forbidden: "measured" dirty-air cost, a "±" or "standard error" on a dirty-air value, and "clean air" or "no dirty air" read from a 0.0 without the lap being measured. At least one pass and one fail example, like the existing rules. `sources` must cite a line that carries the quote: the new `schema.yml` text from step 1, by line, since `sources.node.test.ts` checks every cite against the file.
4. Bump `updated` in `policy.json`. Do not edit any other app file.

**Must not move:** every value in `int_dirty_air_tax_component`, `int_lap_residual_decomposed`, `fct_lap_residuals` and every other `fct_*` (byte oracle); label v16 and `label_stability_baseline.csv`; θ and `theta_air_fit_season_max`.
