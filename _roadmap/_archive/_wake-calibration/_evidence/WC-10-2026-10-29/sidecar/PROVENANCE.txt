Definitions (constants in sidecar.py; the registration WC-10d fixes them):
  exit_speed_kph: car-row speed at apex + 100 m, linear in distance; null if the bracketing car samples are > 50 m apart
  coast_time_s: brake off and throttle < 5 % run immediately before the driver's own car-row brake onset (last rising edge in 300 m before apex), first coast sample to onset sample, capped 300 m; 0 if none observed; null without an onset or when a car-sample gap > 1.0 s lies inside the run
  partial_throttle_share: share of car samples in the pass-table segment with 5 <= throttle < 98; null below 3 samples or without a segment start
  drs_open_approach: any car sample with DRS in (10, 12, 14) in the 300 m before the segment start (the gap window); null without samples or a segment start
  prev_lap_gap_s: pass-table gap_s, same driver and corner, lap - 1; null if that pass is missing or had no car ahead (prev_lap_clear_ahead tells them apart); never 0

Caveats: car rows are ~4 Hz (median 0.24 s / 13 m; p90 0.40 s / 25 m). Exit speed interpolates across that spacing; coast time resolves to one sample interval (~0.24 s) and is a lower bound; brake is on/off only, so onset shifts under one sample spacing are invisible; throttle share is a sample share, not time-weighted. coast_time_s is null where the driver did not brake (flat corners), by definition.
