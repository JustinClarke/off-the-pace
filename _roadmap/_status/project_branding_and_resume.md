## Resume Titles & Bullet Points
If you are listing this project on a resume, you want the title to immediately convey the complexity and scope of the engineering and math involved.

* **Creator | Probabilistic State Estimation Framework for Motorsport**
* **Lead Engineer | Latent Dynamics Inference Engine**

* **Project Lead | F1 Telemetry Inference & Counterfactual Engine**

### Example Resume Bullet Points
* Designed and implemented a probabilistic inference engine to estimate latent vehicle states (e.g., thermal load, core wear) from sparse 10Hz telemetry data.
* Shifted from heuristics-based event detection to a continuous-time generative model, utilizing energy-driven degradation mechanics instead of discrete lap-based metrics.
* Developed a counterfactual simulation framework allowing for dynamic racing strategy re-evaluations based on hidden physical states.
* Architected a data pipeline (SQL/dbt) to normalize multi-dimensional track factors (e.g., dirty air, 3D track gradients) for unbiased state estimation.
