TX-01. Order-statistic rank j for a distribution-free CI of a median. For n values sorted x_1 &lt;= ... &lt;= x_n, [x_j, x_&#123;n-j+1&#125;] covers the population median with probability &gt;= 1 - 2 * alpha_half, where j is the largest k with P(Bin(n, 1/2) &lt;= k - 1) &lt;= alpha_half. No such k exists for small n (n &lt; 6 at alpha_half = 0.025): j is NULL there and so is the CI. Known values at 0.025: n = 6 -&gt; 1, n = 10 -&gt; 2, n = 20 -&gt; 6. Deterministic (no bootstrap). Binomial pmf from lgamma; the running CDF is compared with a 1e-12 tolerance (a Bin(n, 1/2) CDF is a dyadic rational, so it never equals 0.025 exactly and the tolerance only absorbs float error). Returns a SELECT with columns (n, ci_rank_j), one row per distinct n &gt;= 1 in n_relation.n_col. Use it as a CTE body.
