One row per constructor (team). Derived from stg_laps with a manually maintained power-unit family mapping, one family per team name (not per season). pu_family is a reference attribute: it is carried onto fct_lap_residuals and fct_driver_skill_features, and no pace index or model reads it. A team rename arrives as a new constructor_id and needs its own mapping row; assert_pu_family_coverage warns while any constructor is 'unknown_pu'.
