One row per constructor (team) name, from a fixed list in the model rather than from the loaded laps (CO-29), so every build, the CI fixture included, has every team. pu_family is one family per team name (not per season); it is a reference attribute carried onto fct_lap_residuals and fct_driver_skill_features, and no pace index or model reads it. A team rename arrives as a new constructor_id and needs its own row; a name missing from the list fails the stg_laps.constructor_id relationships test. constructor_lineage_id groups the names one team has raced under (a rename is the same team, owner's ruling 2026-10-23).
