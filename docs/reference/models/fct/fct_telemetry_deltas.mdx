Driver-vs-teammate corner-metric deltas. Grain: one row per (race_id, driver_a, driver_b, corner_name, lap_number) for each teammate pair (same constructor_id in that race, driver_a &lt; driver_b), the per-corner difference in braking point, minimum corner speed, and throttle-application point. Built by FULL OUTER joining the two teammates' int_corner_metrics on corner and lap, so a corner either driver measured has a row; a delta is NULL where either side is missing, never 0 (CO-22; before it, every driver in the race was paired with every other and unmatched corners were written as 0). Exported to the app's data bundle but has no current app feature consumer.
