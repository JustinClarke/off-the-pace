One row per driver-race, shaped for plain-language explanations ("why so slow at Monza"). Grain: (driver_id, race_id). rating_s is int_driver_race_skill_loro's driver_skill_loro_s (median lap-by-lap gap to the teammate; negative = faster). There is no within-race rank: ordering every driver's gap to his own teammate across the field reads as a speed ranking and is not one (CO-01/T4), so it was dropped. ci_low / ci_high (TX-01) are a distribution-free 95% CI for that median, built from the same paired lap gaps (int_driver_race_paired_laps): the order statistics [x_j, x_&#123;n-j+1&#125;] of the n = paired_lap_count sorted gaps, where j is the largest k with P(Bin(n, 1/2) &lt;= k - 1) &lt;= 0.025 (coverage &gt;= 95%). NULL when n &lt; 6, where no such interval exists. Not the season Bayesian CI. rating_trust_label says how far to trust rating_s: suppressed (n &lt; 6), thin (6 &lt;= n &lt; 12), ok (n &gt;= 12). Component means are over ml_eligible laps (seconds, positive = slower).
