One row per lap. Cost of driving in dirty air (turbulent wake) following another car. Uses prior-lap dirty-air intensity to establish causality: current lap slowdown → prior lap's position. Avoids reverse causality. Seconds lost = θ_air × dirty_air_intensity_lag1, capped [0, 5.0] seconds. θ_air is the DECLARED var theta_air_label_value (0.331 s/lap since W40, 2026-09-27), applied as-is. It is fitted from the data, but outside dbt: 06b's pre-registered F2 estimator (partial residual on the lagged dirty-air bit, stint fixed effects plus six tyre-age bins) on this model's two-arm calibration panel, 2018-2025, gives 0.3313 [0.293, 0.370] (_roadmap/_fixes/wi/WI-12-06b-remeasure.md). The pooled OLS slope this model used to fit in SQL (0.5033 on the same panel, WI-01's interim value) billed some car pace as dirty air, because slower cars follow more often. History: an unfitted 0.5 literal through v12 (the panel was filtered to the treated arm, so the slope was unidentified, 08q), 0.1310 (08q, v12 substrate), 0.5033 (WI-01, interim), 0.331 (W40). One θ for every season; per-season fits are published in the 06b post, not carried into the label.
