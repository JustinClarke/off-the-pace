One row per (driver_id, circuit_id). How much faster/slower is this driver at this circuit relative to their career average? circuit_id is the physical-circuit identifier, so renamed events and double-headers at one venue (e.g. mexican_grand_prix / mexico_city_grand_prix) pool into a single track record. Shrunk toward driver mean (Bayesian, prior = 5 virtual races). Negative = faster at this circuit than career average. affinity_confidence [0,1]: &lt; 0.17 = prior-dominated. Identifies drivers who suit high-downforce, street, etc. tracks.
