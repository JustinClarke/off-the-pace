One row per (driver_id, circuit_id). How much better or worse does this driver do against his teammate at this circuit than he does on average? Built on int_driver_race_skill_loro.driver_skill_loro_s (median lap-by-lap gap to the teammate). circuit_id is the physical-circuit identifier, so renamed events and double-headers at one venue (e.g. mexican_grand_prix / mexico_city_grand_prix) pool into a single track record. shrunk_affinity_s is a LEVEL (the shrunk circuit mean gap to the teammate), shrunk toward the driver's own all-circuit mean (Bayesian, prior = 5 virtual races). The affinity itself is affinity_vs_driver_mean_s = shrunk_affinity_s - global_driver_mean_s: negative = better against the teammate at this circuit than the driver's own average (WI-14b, F44: the page used to draw the level, so every cell was green). affinity_confidence [0,1]: &lt; 0.17 = prior-dominated.
