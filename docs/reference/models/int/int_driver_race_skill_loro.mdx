Equal-car driver skill, race grain (race_year, race_id, driver_id). driver_skill_loro_s = MEDIAN(own lap time - teammate lap time) over the clean laps both drivers ran, paired on lap_number (WI-14b, F40, FD5 option C); negative = faster than the teammate; used by the rating chain. It replaced P20(own) minus the teammate's median, which rated lap-time scatter as speed (mean pair sum -1.83 s). driver_skill_field_s = median pace delta minus the de-biased constructor×race FE (int_constructor_car_fe.car_fe_s, car pace net of driver skill); used only by int_driver_circuit_era_affinity / Ghost Car Standings leaderboard, fixing the weak-teammate inflation confound; negative = faster than the car term.
