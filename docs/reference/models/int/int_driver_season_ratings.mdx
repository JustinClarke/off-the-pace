One row per (driver_id, season). Aggregates the race-grain equal-car rating (int_driver_race_skill_loro.driver_skill_loro_s, the median lap-by-lap gap to the teammate) to season grain, shrunk toward the season mean over all drivers (Bayesian, prior = 5 virtual races). Negative = faster than his teammate(s). Teammate-relative, so a car-era shift cancels inside each pair. Intermediate for int_era_normalized_driver_rating.
