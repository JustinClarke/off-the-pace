One row per (driver_id, season). The published driver-season rating. era_adjusted_rating = shrunk_residual_s with NO era offset (WI-14b, F45): the rating is teammate-relative (median lap-by-lap gap to the teammate, F40), so a car-era shift moves both teammates alike and cancels. The old ungated bridge-driver offset (t = -1.5) inverted the between-era field-mean gap. Negative = faster than his teammate(s). The bridge-driver shift is still measured and published as diagnostics (era_shift_global_s, era_shift_se_s, n_bridge_drivers, low_anchor_sample_flag); none of them moves era_adjusted_rating. T35 (assert_era_offset_shrinks_gap) fails if an ungated offset returns.
