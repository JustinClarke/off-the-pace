Air state classification and thermal load from dirty air. One row per stint-lap. Classifies air state per sector (free_air, tow_zone, drs_train, dirty_air) and accumulates cumulative thermal load on tyre surface and bulk using exponential moving average. S2 (the dirty-air third) is classified on the median gap alone: &lt; 1.5 s is dirty_air whatever DRS did (F48, WI-15a). drs_train and tow_zone arise only on the straight thirds (S1/S3), where DRS still splits a sub-1 s follow.
