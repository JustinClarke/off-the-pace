Fuel burnoff and weight correction. One row per valid lap. Calculates fuel_mass_kg based on consumption rate and weight_corrected_lap_time by applying weight penalty from fuel load. WI-05 (F6, F32, F52): the load is priced from the race's SCHEDULED distance (race_scheduled_laps seed) at the season's FIA race-fuel limit (105 kg 2018, 110 kg from 2019), burned evenly over the scheduled laps. It no longer aggregates over the race's own laps, so the aggregation-scope exemption this model used to carry (MAX(lap_number) over valid laps as a proxy for the scheduled distance) is gone with the aggregation.
