One row per lap per sector (3 rows/lap). Breaks down lap-level physics components (fuel, compound, constructor, dirty_air) to individual sectors proportional to sector time. Grain: (lap_id, sector). Allows per-sector skill analysis. Matches stg_sector_times granularity. Identity: sector_pace_delta = sector_components + sector_skill_residual. Note: rubber and ambient components are now part of base_track_pace and are not allocated separately (removed per WI-01).
