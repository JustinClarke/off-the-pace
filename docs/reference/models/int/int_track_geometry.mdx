Circuit geometry (gradient + curvature) from raw X/Y/Z telemetry, binned to 25m distance intervals. Grain is (race_year, track_id, distance_bin) -- per-season, not collapsed to a single per-circuit shape, since GPS origin/heading can drift between seasons (verified at Bahrain: 2019 diverges from 2020-2024). Start/finish bin has NULL gradient/curvature (no wraparound across the lap boundary).
