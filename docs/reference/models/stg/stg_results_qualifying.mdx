Official classified results for the qualifying session. One row per driver × session. The Q1/Q2/Q3 columns are each driver's official best lap in each segment and are populated only on the qualifying session's own results (they are always null on the race session's, which is what stg_results reads). Those times are the anchors int_qualifying_segments matches back to the laps that set them.
