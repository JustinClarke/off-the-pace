# Sessions the source cannot deliver complete. The ingest still runs, and the
# pipeline locks Bronze with these listed as known gaps instead of blocking.
#
# Format, one session per line:
#   YEAR TYPE SLUG | round=N | status=STATUS | reason
# TYPE is R for race or Q for qualifying. round is the manifest round_number.
# status is the manifest status the session is expected to have (ok, thin, skip or
# error). The reason is required and must not be empty. The first three fields stay
# YEAR TYPE SLUG, which is all that verify_bronze.py and pipeline_lib.sh read; the
# build freshness gate (scripts/build_freshness.py) parses every field strictly and
# refuses a malformed line.
# A session listed here is accepted by ingest and verify_bronze when it fails or comes
# back thin. Anything NOT listed still stops the pipeline, so new problems are never
# hidden. Listing a session here does NOT approve it for the build freshness gate:
# only the allow-list in scripts/build_freshness.py (APPROVED_GAPS) does. That list
# covers only the exceptional statuses (error, thin): a listed error or thin session
# that appears in the latest Bronze run and is not on it blocks the build. A session
# whose latest status is ok or a verified skip passes the gate on its own checks,
# listed here or not.
#
# Recorded for information (not blocking, not listed below): position and car data
# the source returns empty. 2018 R australian_grand_prix (pos data); 2018 R
# bahrain_grand_prix (car and pos data; the manifest records no samples). Their other data is written as normal.

# 2018 R australian_grand_prix, KeyError '77' for 2018 R bahrain_grand_prix), so they
# have no circuit_info or circuit_markers. Also without circuit markers (fill pass:
